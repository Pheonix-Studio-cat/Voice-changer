# Stimmwandler

Voice Changer fürs iPhone im Browser: Sprich ins iPhone-Mikrofon, die verwandelte Stimme kommt aus dem verbundenen Bluetooth-Lautsprecher.

**Live:** https://pheonix-studio-cat.github.io/Voice-changer/

## Stimmen
Normal, Chipmunk, Monster, Roboter, Alien, Funkgerät, Höhle – plus Regler für Tonhöhe und Lautstärke.

## So geht's
1. Bluetooth-Lautsprecher mit dem iPhone verbinden (Kopfhörer trennen).
2. Seite in Safari öffnen, Stimme wählen, **Start** tippen.
3. Mikrofon erlauben und sprechen.

Hinweis: iOS schickt den Ton immer an das Bluetooth-Gerät, dessen Mikrofon benutzt wird. Kopfhörer-Mikrofon und separater Lautsprecher gleichzeitig gehen deshalb nicht.
